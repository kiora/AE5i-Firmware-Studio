## 主要问题

| 项目 | 原逻辑 | 处理 |
|---|---|---|
| 硬链接内容 | 重建只读取第一份普通文件，后续副本的编辑可能被忽略 | 哈希核对所有副本，不一致时拒绝 |
| 文件数据完整性 | candidate 仅遍历 inode/目录；可读元数据不代表数据块有效 | 深度读取导入镜像，最终打包也深度验证 |
| 工作目录重建 | 未逐文件核对输出镜像内容 | 比对所有普通文件 SHA-256，并复核构建期间工作目录稳定性 |
| LZO 参数 | 仅传压缩类型和块大小 | 原镜像算法/等级显式传入，输出再次核对 |
| 未编辑工作目录 | 无条件重新压缩，可能改变体积 | 保留原始镜像字节 |
| 解包失败 | 可能留下普通文件半成品和缺失侧边清单 | 临时目录构建并提交，失败回收 |
| 特殊节点关联 | 硬链接只覆盖普通文件 | 按 inode 关系生成硬链接，并验证设备/FIFO/软链接 |
| Windows junction | is_symlink 不足以覆盖重解析点 | lstat 属性检查且逐级遍历 |
| 工程清单 | 缺项、重复名称可能被接受 | 19 项全量、无重复、原槽位长度一致 |
| 固定分区格式 | 损坏魔数可能被识别为 binary，跳过文件系统验证 | 固定配置要求保持原分区类型 |
| 扩展属性 | 只摘要 ID 表之后的字节 | 覆盖实际 xattr 值存储区与 ID 表 |
| MCU 行校验 | 源分区行 checksum 错误，仅在重新导入该分区时修复 | 正常打包也处理合法 S-record 行校验 |
| 版本与诊断 | 后端仍为 1.0.0，缺少 stderr 上报 | 版本同步；日志回退与后端错误记录 |
